# 🎨 VibeUI Designer — God-Level Frontend & UI/UX Engineering Skill

> **Target Agents**: Google Antigravity, Claude Code, Cursor, Windsurf.  
> **Mission**: Annihilate generic, flat, boring "AI-generated" web interfaces (flat `#111` gray boxes, default blue buttons, lack of typography hierarchy) and construct **world-class, visually magnetic, production-grade UIs**.

---

## ⚡ Core Operational Workflow

When tasked with building or polishing any UI:
1. **Determine Design Paradigm**: Select one of the 6 Master Themes:
   - *Cyberpunk HUD* (tools, security, audio/video, crypto)
   - *Linear Minimal* (SaaS, devtools, cloud, issue trackers)
   - *Glassmorphism 2.0* (consumer web, portfolios, creative apps)
   - *Deep Space Cosmic* (AI studios, spatial compute)
   - *Neobrutalism* (bold viral apps, fintech, creative portfolios)
   - *Nordic Clean Light* (editorial, documentation, health)
2. **Apply Ambient Canvas Depth**: Layer the background with deep navy/slate blacks, radial lighting blobs, and translucent backdrop-blur cards.
3. **Enforce Dual Typography**: Combine an interface body font (`Inter`/`Geist`) with a monospace font (`JetBrains Mono`) for all stats, badges, and code.
4. **Structure via Bento Grids**: Layout cards asymmetrically with hero interactive visualizers.
5. **Add Tactile Micro-Affordances**: Hover lifts, click scale compressions, glowing focus rings, and animated status dots.
6. **Execute Pre-Flight Audit**: Verify the interface against the [25-Point Design Audit Checklist](./references/design-audit-checklist.md).
